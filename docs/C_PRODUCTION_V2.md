## 本地导入草稿
先解压 C 版 v2 ZIP，再从本仓库根目录运行：

node scripts/import-art-pack.mjs /path/to/chef-bubu-C-v2 --draft

脚本只复制到 assets/cards/chef-bubu/drafts/v2，不会修改现有卡牌目录和在线演示；正式入库前必须经过视觉验收。

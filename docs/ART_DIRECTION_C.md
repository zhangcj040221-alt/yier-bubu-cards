# C 全息晶彩 · 美术母版（2026-11-01）

**已选择：第三张「全息晶彩厨师布」**（三张对比里的最右/第三张）。

此文件锁定艺术方向，不表示现有 Three.js 预览已达到美术标准。旧版网页内的角色 SVG 和程序背景仍是**技术占位**，不得以此冒充已验收的卡牌。

## 美术契约

1. 卡身竖版约 3:4，明亮通透；卡面内温暖阳光厨房，前中后景自然、有深度。
2. 香槟金细框，四角少量水晶切面，顶部/底部可用小型菱形宝石作为品质纹章。**不要厚重、喧宾夺主的水晶堆。**
3. **镀闪是卡面印刷膜材**：背景/插画的彩虹反射随倾斜改变；金属框和宝石可以有自身材质反光，但不代替卡面镀闪。
4. 角色以用户认可的原版造型为准：正面轮廓、五官、比例、厨师帽、红领巾、锅铲与炒锅不可为追求「3D」擅自重绘。
5. 名牌材质独立、文字程序叠加，星级独立；主题变化时不重复画已存在的公共装饰。
6. 只把真实独立素材放入正式的角色/背景/前景层。把整张平面图简单裁切不能算真分层。

## 批量生产顺序

**先批量化美术母版，后接入 Three.js**：

认可静态母版 → 准备原画透明角色 + 无人场景背景 + 前景层 → 复用 frame/nameplate/foil → 加入 catalog 配置 → 手机实际镀闪和视差验收 → 才升级为正式卡牌。

不要为了技术占位图反向降低美术标准。
